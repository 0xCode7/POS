# مطعم أفندينا — Restaurant POS v0.2.1

> نسخة Electron Desktop تجريبية لنظام Windows وLinux. ليست إصدارًا جاهزًا للإنتاج.

## نبذة عن البرنامج

مطعم أفندينا هو نظام نقطة بيع محلي لمطعم واحد، مخصص لطلبات الكاونتر/التيك أواي. يعمل التطبيق دون خدمة سحابية أو اتصال إنترنت وقت التشغيل، ويحتفظ ببياناته محليًا على الجهاز.

## المميزات الرئيسية

- واجهة كاشير عربية RTL، وتصنيفات وأصناف سهلة الإدارة.
- أدوار منفصلة للمدير والكاشير وجلسات محمية محليًا.
- تحصيل نقدي وإيصالات مدفوعة، مع تخطيطات طباعة 58mm و80mm.
- تقارير مبيعات، سجل إيصالات، وبحث تاريخي؛ الإيراد ليس ربحًا.
- نسخ احتياطي يومي ويدوي، أسماء نسخ مخصصة، واختيار مجلد آمن للنسخ.
- استعادة مضبوطة عبر Supervisor بعد إعادة مصادقة المدير وإبطال الجلسات القديمة.

## طريقة التشغيل على Windows

شغّل `RestaurantPOS-Setup.exe` للتثبيت، أو فك ضغط `RestaurantPOS-Portable.zip` وشغّل تطبيق Electron. لا يحتاج المستخدم إلى Node.js ولا يفتح التطبيق متصفحًا خارجيًا.

## طريقة التشغيل على Linux

لـAppImage:

```bash
chmod +x RestaurantPOS-Linux-x64.AppImage
./RestaurantPOS-Linux-x64.AppImage
```

لـDebian/Ubuntu:

```bash
sudo apt install ./RestaurantPOS-Linux-amd64.deb
```

اختبار تثبيت DEB على نظام فعلي منفصل يبقى مطلوبًا قبل اعتماده تشغيليًا.

## البيانات والنسخ الاحتياطية

يحفظ التطبيق SQLite والإعدادات والنسخ الاحتياطية خارج مجلد التثبيت. استخدم قرصًا خارجيًا للنسخ المهمة؛ النسخ على القرص نفسه مفيدة لبعض أخطاء التشغيل فقط ولا تحمي من تعطل القرص.

## الأمان والخصوصية

تعمل الخدمة على loopback المحلي ولا تتطلب حسابًا سحابيًا. تظل الحماية الفعلية مرتبطة بحماية حساب نظام التشغيل، وقفل الشاشة، وتشفير القرص، والوصول الفيزيائي إلى جهاز المطعم.

## حالة الاختبارات

تم بناء والتحقق من حزم Windows وLinux، checksums، وتشغيل AppImage المحلي ببيانات معزولة. تم اختبار سير عمل Electron على Linux. يبقى اختبار واجهة Windows التفاعلية الفعلي، واختبار تثبيت DEB على بيئة مستقلة، والطابعة الحرارية الفعلية غير مكتملين.

## القيود المعروفة

هذا إصدار تجريبي. فتح نافذة الطباعة لا يثبت خروج ورق من طابعة حقيقية، ولا ينبغي استخدامه قبل إجراء اختبار قبول على جهاز المطعم المستهدف.
