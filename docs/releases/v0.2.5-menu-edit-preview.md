# مطعم أفندينا — Restaurant POS v0.2.5

> **إصدار تجريبي لنظام Windows x64.** مناسب للتثبيتات الجديدة ولترقية
> تطبيق Electron الحالي بعد اجتياز فحص الترقية الآلي. لا يُعتمد بعد لترقية
> تثبيت Inno Setup القديم الذي يحتوي بيانات عميل حقيقية؛ يلزم التحقق اليدوي
> التفاعلي الموثق في `docs/WINDOWS_INSTALLER.md` قبل ذلك.

## ما الجديد

- زر **تعديل** ظاهر لكل تصنيف في إدارة المنيو، مع نافذة عربية مسبقة التعبئة
  للحفظ أو الإلغاء.
- تعديل الصنف من نافذة عربية مسبقة التعبئة: الاسم، الوصف، السعر بالجنيه،
  والتصنيف. يحتفظ التعديل بنفس معرّف الصنف ويمكن نقل الصنف بين التصنيفات.
- تحديث فوري لواجهة نقطة البيع بعد الحفظ.
- تغطية API وChromium لتعديل التصنيفات والأصناف، منع صلاحية الكاشير، وثبات
  أسعار وأسماء الإيصالات والتقارير المدفوعة تاريخيًا.
- يحتوي أيضًا على سجل المشتريات الإداري الموجود في المهاجرة
  `0005_purchases.sql`.

## سلامة البيانات

تُنشئ الطلبات لقطة لاسم الصنف وسعره عند إضافته، ويحفظ الإيصال لقطة مستقلة عند
الدفع. لذلك فإن تعديل المنيو يؤثر على الطلبات الجديدة فقط؛ لا يغير إيصالات
مدفوعة أو المدفوعات أو تقارير مبيعات سابقة. لا توجد مهاجرة قاعدة بيانات جديدة
في هذا الإصدار.

## حدود التحقق

- يجب التحقق من الملفات قبل التشغيل باستخدام `SHA256SUMS.txt`.
- طباعة الإيصال تفتح نافذة الطباعة العادية؛ لا يوجد ادعاء بالطباعة الصامتة أو
  بطباعة جهاز فعلي.
- ترقية Electron الحالية تختبر على بيانات مؤقتة مع الاحتفاظ بقاعدة SQLite في
  `%LOCALAPPDATA%\RestaurantPOS\data\restaurant-pos.sqlite`.
- ترقية Inno Setup القديمة إلى Electron ما زالت **غير متحققة** على سطح مكتب
  Windows تفاعلي، ولذلك لا يصح وصف هذا الإصدار بأنه آمن لكل مسارات الترقية.
